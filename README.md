# 📚 BookSearch

A React-based book search web application built using Vite and JavaScript.

## 🚀 Features

- Search for books easily
- Responsive user interface
- Fast rendering using Vite
- Reusable React components
- Simple and clean UI design

---

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- HTML
- CSS

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Trijayee/BookSearch.git
```

Go to the project folder:

```bash
cd BookSearch
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
